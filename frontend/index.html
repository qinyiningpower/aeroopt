About This System

This system is a web-based interactive platform that combines AI analysis, physics visualization, and modern UI design to help users understand automotive aerodynamic performance in a clear and intuitive way.

It allows users to explore different car models, visualize airflow-related data such as pressure distribution, and receive AI-generated explanations of drag and aerodynamic behavior. The system also supports interactive features like hotspot selection, model switching, and real-time AI chat assistance.
