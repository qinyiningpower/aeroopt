# Contributing

Create a focused branch and explain the problem, resulting behavior, and validation in your pull request. Preserve the distinction between saved results, AI interpretation, and external research computation.

Run `python -m pytest -q` after installing `requirements-dev.txt`. For pipeline changes, install `pipeline/requirements.txt` and exercise the CLI on paired meshes with verified correspondence. Never commit API keys, model weights, raw datasets, registration documents, or personal information.

New cases need explicit provenance, units, matching before/after assets, and a consistent export contract. Do not add performance claims without the evaluation setup and supporting evidence. Identify the author and applicable terms for contributed assets.
